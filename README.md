# Меню недели

Каждое воскресенье в 14:00 по Екатеринбургу бот присылает Наташе ссылку на меню
следующей недели. На странице — 7 дней, на каждый завтрак, обед и ужин по три
варианта с фото и продуктами. Она отмечает 21 блюдо, страница собирает список
покупок на двоих и группирует его по отделам магазина.

В шторке две вкладки: «Продукты» — список покупок, «Рецепты» — все выбранные блюда
по дням с продуктами и шагами. Кнопка «Отправить в телеграм» шлёт одну ссылку,
в которой зашит её выбор (`?p=<дата>.<21 символ>`): открывший её видит те же блюда.

Сервера нет. Страница статическая, лежит на GitHub Pages. Выбор хранится
в браузере Наташи. Отправку раз в неделю делает Cloud Routine — см. `routine.md`.

Количества в каталоге — на одну порцию, а на экране и в списке покупок всё
умножается на двоих (константа `EATERS` в `index.html`).

## Что где

```
data/breakfast.json  30 завтраков   ← сюда добавлять новые блюда
data/lunch.json      30 обедов
data/dinner.json     30 ужинов
data/dishes.json     всё вместе; собирается скриптом, руками не править
index.html           страница выбора и список покупок
photos/<id>.jpg      фото блюд, по одному на блюдо
scripts/build_catalog.py   склейка и проверка каталога
scripts/fetch_photos.py    разовая скачка фото с Pexels
routine.md           инструкция облачному агенту
```

## Как добавить блюдо

1. Дописать объект в `data/breakfast.json`, `lunch.json` или `dinner.json`.
2. Держать правила: активное время не больше 20 минут, количества на **одну**
   порцию, названия продуктов ровно такие же, как в других блюдах
   (иначе не сложатся в списке покупок).
3. `python3 scripts/build_catalog.py` — соберёт `dishes.json` и проверит.
4. `python3 scripts/fetch_photos.py` — скачает недостающие фото.

Скрипт сборки ругается и не собирает файл, если есть ошибки: время больше 20 минут,
повторяющийся `id`, неизвестный отдел, у продукта нет количества, один и тот же
продукт записан в разных отделах либо в разных единицах, **или какой-то продукт
не назван в шагах рецепта**.

## Как посмотреть страницу локально

```bash
python3 -m http.server 8765
open http://localhost:8765/index.html
```

Просто открыть файл двойным щелчком нельзя: браузер запретит читать `dishes.json`.

## Как устроен выбор недели

Страница сама раскладывает каталог: считает понедельник текущей недели
(в воскресенье — завтрашний понедельник), от этой даты берёт число-семя,
перемешивает каталог и раздаёт по три варианта на каждый приём пищи.
Одна и та же неделя всегда даёт одну и ту же раскладку, разные недели — разную.
Поэтому рутине не нужно ничего запоминать.
